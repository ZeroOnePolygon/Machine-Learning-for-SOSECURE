# 🛡️ Malware Detection System (Machine Learning)

โปรเจกต์ระบบตรวจจับมัลแวร์ด้วย Machine Learning (XGBoost) โดยระบบถูกออกแบบให้ทำงานผ่านศูนย์กลางที่ไฟล์ `main.py` ซึ่งแบ่งการทำงานออกเป็นเมนูต่างๆ ที่ใช้งานง่าย ตั้งแต่การรวบรวมข้อมูลดิบไปจนถึงการประเมินประสิทธิภาพของโมเดล (อ้างอิงจาก คู่มือ ML.pdf)

## 📑 Workflow ขั้นตอนการทำงาน

ระบบแบ่งการทำงานออกเป็น 6 ขั้นตอนหลัก ดังนี้:

### 1. Data Gathering (การรวบรวมข้อมูล)
*   **สกัดลักษณะเด่น (Features):** ดึงข้อมูลจากไฟล์ปกติและมัลแวร์ เช่น ขนาดไฟล์ (file_size_bytes), ค่าความไร้ระเบียบ (file_entropy), และประเภทของหัวไฟล์ (magic bytes)
*   **Multiprocessing:** ประมวลผลด้วย CPU หลายแกนแบบคู่ขนานเพื่อความรวดเร็วในการสแกนไฟล์จำนวนมาก
*   **Database:** บันทึกข้อมูลทั้งหมดลงฐานข้อมูล `malware_analytics.db`

### 2. Database Management (การจัดการฐานข้อมูล)
*   **Merge:** รวมฐานข้อมูลหลายๆ ไฟล์เข้าด้วยกัน พร้อมระบบกรองข้อมูลแฮช (SHA256) ที่ซ้ำซ้อนอัตโนมัติ
*   **Clean:** ล้างไฟล์ขยะและไฟล์ที่มีนามสกุลไม่เกี่ยวข้องออกเพื่อลดความสับสนของข้อมูล

### 3. Data Cleaning (การทำความสะอาดข้อมูลก่อนสอน AI)
*   **Filter:** คัดกรองขนาดไฟล์และค่าเอนโทรปีให้อยู่ในเกณฑ์ที่เหมาะสม
*   **Outlier Detection:** ใช้อัลกอริทึม IsolationForest ตรวจหาและกำจัดข้อมูลที่ผิดปกติ
*   **Export:** บันทึกข้อมูลที่สะอาดลงตาราง `malware_features_train_clean`

### 4. EDA (Exploratory Data Analysis)
*   วิเคราะห์ความสัมพันธ์ของข้อมูล (Correlation Heatmap)
*   ตัวแปรที่มีผลกระทบสูงสุด 4 อันดับ: `block_size` (51.47%), `num_sections` (29.74%), `file_entropy` (10.80%), และ `file_size_bytes` (7.99%)

### 5. Model Training (การสอนปัญญาประดิษฐ์)
*   **Algorithm:** XGBoost (XGBClassifier)
*   **Data Split:** Train 60%, Validation 20%, Test 20%
*   **Tuning:** ปรับค่าความลึก (max_depth=5), ใช้ `scale_pos_weight` จัดการ Imbalanced Data และตั้งค่า `early_stopping_rounds=30` เพื่อป้องกัน Overfitting
*   **Export Model:** บันทึกสมอง AI ออกมาเป็นไฟล์ `malware_modelV2.bin` พร้อมใช้งาน

### 6. Evaluation (การประเมินประสิทธิภาพ)
ประเมินผลกับชุด Test ข้อมูลจำนวน 21,136 ไฟล์ (ไฟล์ปลอดภัย 12,044 ไฟล์, มัลแวร์ 9,092 ไฟล์)

## 📊 ประสิทธิภาพของโมเดล (Performance Metrics)

*   **Accuracy (ความแม่นยำรวม):** `92.67%`
*   **Recall (Malware):** `90.09%` (ดักจับมัลแวร์ได้ 8,218 ไฟล์)
*   **Precision (Malware):** `92.67%` (อัตราแจ้งเตือนผิดพลาดเพียง 7.33%)
*   **AUC (ROC Curve):** `0.978` (ความสามารถในการแยกแยะมัลแวร์ดีเยี่ยม)
*   **Best Threshold:** `0.514` (จุดตัดคะแนน F1-Score ที่ดีที่สุด)

## 🚀 วิธีการใช้งาน (Getting Started)

1. **ติดตั้งไลบรารีที่จำเป็น:**
   ```bash
   pip install -r requirements.txt
   ```
2. **รันโปรแกรมหลัก:**
   ```bash
   python main.py
   ```
3. **ขั้นตอนในเมนู:**
   * เลือกเมนู **Data Gathering** เพื่อเก็บข้อมูลทีละโฟลเดอร์ (ระบุความเสี่ยง: 0 = ปกติ, 1 = มัลแวร์)
   * เมื่อได้ข้อมูลครบ ให้เข้าเมนู **EDA/Model Training** เพื่อทำความสะอาดและเทรนโมเดล
   * โปรแกรมจะสร้างไฟล์ `malware_modelV2.bin` สำหรับนำไปใช้ตรวจจับมัลแวร์ในระบบอื่นๆ ต่อไป
